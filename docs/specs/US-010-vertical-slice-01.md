## User Story

As a HomeLab visitor, I want a coherent first journey from forest approach to an interactive Software Engineering Lab architecture, so I experience wonder and credible engineering in one inspectable slice.

## Candidate Journey

`forest approach → exterior → main energy portal → central atrium → Zavit placeholder → holographic table → bridge → Software Engineering Lab → interactive architecture`

## Known Constraints

- One entrance portal; normal movement is continuous walking.
- No private Second Brain access or unverified professional claims.
- Semantic, keyboard, mobile-adapted, and reduced-motion paths are required.
- Architecture simulation values are labeled `SIMULATION`.
- Performance budgets are provisional until this slice measures them.
- Graybox and framework/asset spikes precede visual fidelity.

## Refinement Required Before READY

- Define visitor behavior, movement model, interaction model, and slice endpoint.
- Define observable acceptance criteria for each journey step.
- Accept rendering framework, hosting baseline, asset pipeline, content delivery, and degraded-mode decisions through ADRs where needed.
- Identify verified professional evidence allowed in Software Lab.
- Define visual references, target devices, test matrix, and measurement evidence.
- Reconcile `PERFORMANCE_BUDGET.md` against selected rendering and asset-pipeline ADR before this story becomes `ACCEPTED`.
- Split scope if the slice cannot remain independently inspectable.

## Out of Scope Until ACCEPTED

All scenes, shaders, models, 3D components, portfolio backend, migrations, and cloud infrastructure.
